## 💡 Why PrivaClip?

Most mainstream clipboard managers store history in unencrypted SQLite/JSON databases on disk, sync through proprietary cloud servers, or inject background telemetry beacons. That works until you copy a **2FA recovery code, an API private key, medical records, or confidential Slack messages**.

**PrivaClip** takes the zero-trust stance:
1. **At-Rest Hardware Encryption**: Every clipboard entry (text, rich-text, screenshots) is sealed with **AES-256-GCM** using a symmetric key stored in the **macOS Keychain** (`kSecAttrSynchronizable = false`, device-locked, never syncs to iCloud).
2. **Zero Network Footprint**: Neither `Network.framework` nor `CFNetwork.framework` are linked to the binary. Entitlements explicitly block incoming and outgoing network sockets at the kernel level.
3. **Password Vault Protection**: Automatically recognizes and discards transient/concealed pasteboard types (`org.nspasteboard.TransientType`, `ConcealedType`, `AutoGeneratedType`) generated by 1Password, Bitwarden, and KeePass.
4. **Pure Native Performance**: Ultra-compact 1.9 MB native ARM64 binary with `< 0.1% idle CPU` and `< 40 MB RAM`.

## 🚀 Installation

### Option 1: Homebrew Cask (Recommended)

You can install PrivaClip via Homebrew using our dedicated GitHub tap:

```bash
# Tap and install in one standard command
brew install --cask <GITHUB_USERNAME>/tap/privaclip
```

Or tap explicitly:
```bash
brew tap <GITHUB_USERNAME>/tap
brew install --cask privaclip
```

To upgrade in the future:
```bash
brew upgrade --cask privaclip
```

---

### Option 2: Direct Release Download

1. Download `PrivaClip-macOS-arm64.zip` from the [Latest GitHub Release](https://github.com/<GITHUB_USERNAME>/privaclip/releases).
2. Unzip and drag `PrivaClip.app` into your `/Applications` folder.
3. Open `PrivaClip.app`.
   - *First Launch Note*: If macOS displays a Gatekeeper prompt for ad-hoc signed releases, right-click `PrivaClip.app` → **Open** → **Open**.

---

### Option 3: Build From Source

Requirements: macOS 14+ (Sonoma/Sequoia), Apple Silicon Mac (M1–M4), and Swift 5.9+.

```bash
# 1. Clone repository
git clone https://github.com/<GITHUB_USERNAME>/privaclip.git
cd privaclip

# 2. Run automated verification test suite
swift run PrivaClipTests

# 3. Build & package signed release bundle
./scripts/build_app.sh

# 4. Launch app
open build/PrivaClip.app
```

## ⌨️ Keyboard Shortcuts & Usage

PrivaClip runs unobtrusively from your macOS Menu Bar (`LSUIElement = true`).

| Shortcut | Context | Action |
|---|---|---|
| `⌥V` (Option + V) | Global (Any App) | Toggle PrivaClip floating panel |
| `↑` / `↓` | History Panel | Navigate through clipboard items |
| `Return` (`↩`) | History Panel | Paste selected item into active app |
| `⌘C` | History Panel | Copy item back to clipboard (without pasting) |
| `⌘P` | History Panel | Pin / Unpin selected entry |
| `Delete` (`⌫`) | History Panel | Delete item from encrypted history |
| `⌘F` | History Panel | Focus instant search field |
| `⎋` (Escape) | History Panel | Dismiss history panel |
| `⌘,` | Menu / Panel | Open Preferences Window |

## 🛡️ Verifying the Zero-Network Guarantee

You can independently audit PrivaClip's binary to verify that no network code exists:

```bash
# 1. Audit linked dynamic frameworks (Apple system frameworks only)
otool -L /Applications/PrivaClip.app/Contents/MacOS/PrivaClip

# 2. Audit kernel-enforced network isolation entitlements
codesign -d --entitlements - /Applications/PrivaClip.app
```

*Expected Entitlements Output*:
```xml
<key>com.apple.security.network.client</key>
<false/>
<key>com.apple.security.network.server</key>
<false/>
```

## 🔐 Permissions Rationale

| Permission | Reason | Behavior If Denied |
|---|---|---|
| **Accessibility** (`AXIsProcessTrusted`) | Required to synthesize `⌘V` into your target application for auto-paste. | Automatically falls back to copying to the clipboard and displays a prompt to press `⌘V` manually. |
| **Input Monitoring** | **Not Required.** | PrivaClip uses Apple's native Carbon HotKey API (`⌥V`), which never inspects or logs user keystrokes. |
